# Tio Dinho — V2 com acervo mestre

Esta versão mantém a V2 visual e acrescenta um acervo mestre dentro de `tiodinho/assets/acervo-master/`.

Foram incorporadas **177 imagens web-ready**, com duplicatas exatas eliminadas e conversão para WebP para reduzir o peso do repositório.

Pastas:
- `tio-dinho/`: fotografias e imagens enviadas para o projeto Tio Dinho.
- `paulistania/`: acervo visual organizado da Paulistânia Desvairada.
- `midia/`: imagens da página Na mídia da Paulistânia, disponíveis para a página Na mídia do Tio Dinho.
- `autores/`: retratos de autores disponíveis no acervo.

`manifest.json` registra o nome original de cada imagem e o arquivo correspondente no acervo. A imagem estar no acervo não significa que esteja exibida no site; a finalidade é permitir futuras trocas diretamente pelo GitHub sem novo upload manual.
