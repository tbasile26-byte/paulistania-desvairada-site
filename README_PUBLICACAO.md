# Tio Dinho — Site V1

Pacote pronto para publicação em `https://cozinhaculturaearte.com.br/tiodinho/`.

## Como publicar
Copie a pasta `tiodinho/` inteira para a raiz do repositório que já contém `paulistaniadesvairada/`. Faça commit/push no GitHub. O Vercel conectado ao repositório deve publicar automaticamente.

## Já incluído
- páginas completas e responsivas
- imagens reais otimizadas em WebP
- metatags de SEO, Open Graph, canonical e JSON-LD Restaurant
- sitemap.xml e robots.txt
- navegação mobile
- links de reserva por WhatsApp
- formulário de mailing conectado ao Apps Script já usado pela Paulistânia
- formulário de Eventos incorporado a partir do Google Forms existente
- PDF do cardápio atual como snapshot

## Pontos para a próxima revisão
1. Substituir `assets/cardapio-atual.pdf` pelo link definitivo do cardápio no Google Drive quando o URL for fornecido.
2. Inserir o PDF do livreto de `Primaveras de uma Vida`.
3. Verificar/ativar notificação por e-mail do formulário de Eventos. O formulário incorporado grava respostas pelo Google Forms; a entrega de e-mail depende da configuração do formulário/Apps Script.
4. Completar a página `midia.html` com clippings específicos do Tio Dinho.
5. Se desejar, substituir as aproximações tipográficas web por fontes licenciadas já disponíveis no seu ambiente de publicação.

## Observação de SEO
Os canonicals foram configurados para `https://cozinhaculturaearte.com.br/tiodinho/`. Se o caminho final for outro, faça busca/substituição antes da publicação.
