# Tio Dinho — Site V2

Versão visual revista a partir da V1 publicada.

Principais mudanças:
- nova primeira imagem: palmito pupunha do menu Primaveras de uma Vida;
- tipografia de títulos mais alta, estreita e editorial, aproximando a linguagem visual do logotipo;
- home reconstruída mais próxima do protótipo aprovado;
- presença muito maior de fotografia contextual;
- PFs do dia ampliados na Home e no Cardápio;
- autores passam a aparecer visualmente nas páginas de menus;
- novas faixas editoriais, mosaicos e blocos de imagem;
- estrutura técnica, SEO, links e integrações da V1 preservados.

Observação: nesta versão entram os retratos de autores já disponíveis no acervo do projeto. Os demais retratos de Primaveras permanecem em cards tipográficos até serem incorporados com imagens devidamente selecionadas/licenciadas.
